# همیار انتخاب | Entekhab Eitaa MiniApp

برنامک خدمات هوشمند فناوری اطلاعات گروه انتخاب در پیام‌رسان ایتا.

> وضعیت: Phase 0 — پایه‌گذاری معماری و قراردادها. این مخزن مستقل است و به کدهای کلاینت وب یا بات بله وابستگی مستقیم ندارد.

## هدف

ارائه یک تجربه فارسی، راست‌به‌چپ و موبایل‌محور برای دسترسی کارکنان به خدمات فناوری اطلاعات از طریق ایتا؛ با استفاده از Gateway سازمانی به‌عنوان تنها مرز ارتباط با سرویس‌های داخلی.

## دامنه نسخه اول

- صفحه اصلی و دسترسی به خدمات
- گفتگوی هوشمند از طریق Gateway
- ایجاد و پیگیری درخواست پشتیبانی (Ticket)
- جستجوی پایگاه دانش فارسی
- نمایش پروفایل و وضعیت نشست
- اتصال امن به محیط برنامک ایتا

## معماری در یک نگاه

`Eitaa WebView → React Mini App → Entekhab API Gateway → Assistant / Ticket Manager / RAG`

کلاینت به Assistant، RAG، Active Directory، دیتابیس یا Ticket Manager اتصال مستقیم ندارد. جزئیات endpointها و claims باید با پیاده‌سازی واقعی Gateway تطبیق داده شوند؛ این مخزن قراردادهای موجود را جعل یا بازتعریف نمی‌کند.

## شروع توسعه

نیازمندی‌ها: Node.js نسخه LTS و npm.

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

برای اجرای محلی خارج از ایتا، برنامه باید در حالت browser-preview اجرا شود؛ این حالت هویت ایتا را شبیه‌سازی یا معتبر اعلام نمی‌کند.

## تنظیمات محیط

فایل `.env.example` را به `.env.local` کپی کنید. فقط آدرس عمومی Gateway مجاز است در متغیرهای `VITE_*` قرار گیرد. هیچ Bot Token، Service JWT، کلید خصوصی یا Secret نباید در Frontend قرار بگیرد.

## وضعیت پیاده‌سازی

در این مرحله، اسکلت فرانت‌اند، مرزبندی لایه‌ها و مستندات پایه ایجاد می‌شوند. اتصال واقعی به Gateway، احراز هویت سمت سرور و تست داخل کلاینت ایتا تا زمان تأیید قراردادهای موجود و فراهم شدن محیط HTTPS، تکمیل‌شده محسوب نمی‌شوند.

## انتشار

طبق مستند رسمی ایتا، برنامک به دامنه HTTPS و ثبت مقصد در سامانه ایتایار نیاز دارد. اجرای برنامک در حال حاضر طبق مستند Quick Start در نسخه Android و Desktop ایتا پشتیبانی می‌شود؛ پشتیبانی iOS یا مرورگر عمومی را نباید فرض کرد.
